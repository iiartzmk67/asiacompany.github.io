# Graphic Designer Portfolio

موقع Portfolio ثابت جاهز للنشر على GitHub Pages.

## الملفات
- `index.html` — محتوى الموقع.
- `style.css` — التصميم.
- `script.js` — القائمة والفلاتر.
- `assets/` — ضع صور أعمالك هنا.

## الصور
استبدل الملفات التالية بصورك:
`hero.jpg`, `project-01.jpg` ... `project-06.jpg`

## معلومات التواصل
افتح `index.html` وعدّل:
- YOUR NAME
- البريد الإلكتروني
- رابط WhatsApp
- روابط Instagram / Behance / Facebook
- النصوص والإحصائيات

لا تحتاج إلى أي مكتبات أو سيرفر. الموقع Static ويعمل مباشرة على GitHub Pages.
